# Отчёт по MVP текстового поиска музыки

## Что реализовано

Собран работающий прототип поиска музыкальных треков по текстовому описанию.
Пользователь вводит желаемое настроение, стиль, темп или особенности звучания,
после чего система возвращает наиболее близкие треки и сгенерированные для них
описания.

В Streamlit UI доступны:

- текстовое поле поискового запроса;
- выбор между TF-IDF и Qwen;
- выбор prompt-инструкции для Qwen;
- настройка количества результатов;
- similarity score, исполнитель, название и описание каждого трека;
- таблица offline-метрик.

## Подготовленные данные

Каталог содержит **1080 треков** с описаниями, полученными с помощью Audio
Flamingo 2.

Объединены четыре файла синтетических интентов:

- **416 уникальных треков**;
- **1248 запросов**;
- ровно **3 запроса на каждый трек**;
- все треки из интентов присутствуют в каталоге.

Из запросов удалены генеративные вводные конструкции: `this is`, `this track
is`, `the song features` и похожие. Очистка изменила **745 запросов**.

Сомнительные строки не удалялись автоматически, а были отмечены флагами:

- 101 строка с повторяющимся текстом запроса;
- 100 запросов с точным значением BPM;
- 136 вероятно оборванных запросов.

Разбиение выполнено по трекам, поэтому один трек не попадает в разные части:

| Split | Треки | Запросы |
|---|---:|---:|
| Train | 291 | 873 |
| Dev | 62 | 186 |
| Test | 63 | 189 |

## Модели

В качестве простого baseline реализован TF-IDF по словам и биграммам.

Основная модель — `Qwen/Qwen3-Embedding-0.6B`. Эмбеддинги всех описаний
предварительно рассчитаны и сохранены:

- 1080 векторов;
- размерность 1024;
- L2-нормализация;
- поиск по cosine similarity;
- документы кодируются без инструкции;
- prompt применяется только при кодировании запроса.

Модель работает на NVIDIA GeForce GTX 1650 через CUDA в FP16. Построение индекса
заняло 4 минуты 46 секунд.

## Численные результаты

Оценка выполнена на test split: 63 целевых трека, 189 строк запросов и поиск по
полному каталогу из 1080 кандидатов. Одинаковые тексты запросов учитываются как
multi-positive.

| Модель / prompt | Recall@1 | Recall@5 | Recall@10 | MRR@10 |
|---|---:|---:|---:|---:|
| TF-IDF | 1.06% | 3.72% | 5.85% | 2.11% |
| Qwen `caption_match` | **2.13%** | **6.38%** | 7.45% | **3.41%** |
| Qwen `balanced` | 1.60% | 4.26% | **8.51%** | 3.09% |
| Qwen `listener_search` | 1.60% | 5.85% | 7.45% | 3.04% |

Лучший результат по Recall@1, Recall@5 и MRR@10 показал prompt
`caption_match`:

```text
Instruct: Given a short description of music, retrieve track descriptions for
music with the same mood, style, energy, rhythm, instruments, vocals, and sound
Query: {query}
```

Prompt `balanced` показал лучший Recall@10. В UI можно переключать инструкции
без пересчёта эмбеддингов каталога.

Отдельная численная оценка Qwen без prompt-инструкции пока не завершена, поэтому
результат без prompt в таблицу не включён.
